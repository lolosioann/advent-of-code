# Advent Of Code Solutions
This repository contains my solutions to the Advent of Code programming challenges. 
Each year, a different programming language is used to solve the puzzles,
in order to explore and learn new languages and their philosophies.

## Structure
- Each year's solutions are organized in separate directories named after the year (e.g., `2025`, `2024`, etc.).
- Inside each year's directory, there are subdirectories for each day's challenge (e.g., `01`, `02`, etc.).
- Each day's directory contains the solution files and any necessary input files.

In order to find the puzzle descriptions, visit the official [Advent of Code](https://adventofcode.com/) website.

## Languages Used
- 2025: `Python`
