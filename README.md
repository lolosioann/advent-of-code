# Advent Of Code Solutions
This repository contains my solutions to the Advent of Code programming challenges. 
Each year, a differnt programming language is used to solve the puzzles,
in order to explore and learn new languages and their philosophies.

## Structure
- Each year's solutions are organized in separate directories named after the year (e.g., `2020`, `2021`, etc.).
- Inside each year's directory, there are subdirectories for each day's challenge (e.g., `1`, `2`, etc.).
- Each day's directory contains the solution files and any necessary input files.

## Languages Used
- 2025: Python
