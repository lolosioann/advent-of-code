# Advent of Code Solutions

My solutions to the [Advent of Code](https://adventofcode.com/) challenges.
Each year uses a different language to explore a distinct programming paradigm.

## Structure

Each year has its own directory containing:
- Per-day solution directories (`01`, `02`, etc.) with solution and input files
- A markdown file with notes, observations, and a language retrospective
