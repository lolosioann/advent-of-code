# Python — 2025

Python was the obvious first language for this project, a jack of all trades
language, known for its simplicity and extensive standard library. If a problem
has an easy solution, there is probably a way to do it in Python. It is also a
language I am pretty familiar with. The goal here isn't to learn Python, but to
establish a reference point: a year solved comfortably, in a familiar language,
to have something to compare every subsequent year against.

## Cool features

- List comprehensions
- Extensive standard library: `itertools` + `functools` are super useful
- String, array repetition (`pattern * n == s`)

## Not so Cool features

- Types. Annotations often feel noisy and redundant
- Performance. Some problems did not produce a result instantly even though they probably should
- No built-in `argmax` for some reason

- **Day 2**: Python makes repeating pattern detection easy: `pattern * (n // k) == s`
